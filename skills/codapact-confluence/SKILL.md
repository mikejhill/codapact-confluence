# Confluence Cloud

`codapact-confluence` is a command-line client for the Confluence Cloud API, generated by Codapact and
distributed as `codapact-confluence`. The CLI documents itself. This skill only gets it
ready; take every usage detail from the CLI, which always matches the version you run.

Always run it through uvx, as `uvx codapact-confluence ...`. Do not install it with `uv tool install`,
pipx, or pip. Where the CLI's own text says `codapact-confluence ...`, run `uvx codapact-confluence ...`.

## Once per skill load

1. Update the cached copy to the latest release:
   `uvx --refresh-package codapact-confluence codapact-confluence --version`. Later calls in the session
   reuse that copy without checking again.
2. Run `uvx codapact-confluence describe --brief` and read its `start`, `auth`, `exit_codes`, and
   `notes`. They explain readiness, credentials, and how to find commands.
3. Follow `start`: it begins with `doctor`, whose exit code says whether the CLI is ready
   and what to fix.

Do not repeat these steps for every command in the same session.

## For each task

- Find the command with `describe --brief` (on large CLIs it lists groups; then
  `describe GROUP --brief`), then run `uvx codapact-confluence describe COMMAND` for its arguments
  before you first use it. Add `--schemas` when you need the output schema.
- On a non-zero exit, read the error and its hint, and look the code up in `exit_codes`.

## Rules

- Before a command without the `read_only` trait, confirm with the user unless they asked
  for exactly that change. Use `--dry-run` to show what it would send.
- Credentials come from the user. Never ask them to paste a secret into the chat; give them
  the `auth` login command from `describe` to run in their own terminal.
