## Run

With [uv](https://docs.astral.sh/uv/); uvx installs the package and its runtime on first use:

```console
uvx codapact-confluence --help
uvx --refresh-package codapact-confluence codapact-confluence --version   # update to the latest
```

Requires Python 3.13 or newer.

## Credentials

Save once in the OS keyring with `uvx codapact-confluence auth login`, or set per shell:

- `basic`: `CONFLUENCE_BASIC_USERNAME`, `CONFLUENCE_BASIC_PASSWORD`. Use your Atlassian account email as the username and an API token as the password (create one at https://id.atlassian.com/manage-profile/security/api-tokens).
- `session`: `CONFLUENCE_SESSION`. For sites where API tokens are disabled: signs in through a browser window and sends the session cookies.

`<VAR>_COMMAND` runs a command that prints the secret (e.g. a password manager). `uvx codapact-confluence doctor` checks settings, credentials, and connectivity.

## Use

```console
uvx codapact-confluence space list-spaces --keys DOCS
uvx codapact-confluence page get --id 123456 --query body.markdown.value
uvx codapact-confluence page create --space-id 98765 --title 'Release notes' --markdown @notes.md
uvx codapact-confluence page update 123456 --body '{"id":"123456","status":"current","title":"Release notes","version":{"number":2}}' --markdown @notes.md
uvx codapact-confluence describe --brief   # every command, for scripts and agents
```

As a library:

```python
from codapact_confluence import Client

client = Client()
```

## Markdown

Page, blog post and comment bodies are Markdown both ways. `--markdown TEXT|@file|@-`
sets the body to send; commands with `--body-format` read `atlas_doc_format` and return it
as `body.markdown.value`. `--doc-format adf` (or `CONFLUENCE_DOC_FORMAT=adf`) keeps ADF.
Macros are directives such as `::toc{maxLevel=2}`, `:::info`, `:jira[PROJ-1]`; run
`uvx adflux macros NAME` for a macro's parameters and `uvx adflux syntax` for the dialect.

## Sign-in

Set `--base-url` (or `CONFLUENCE_BASE_URL`) to your site, for example
`https://your-site.atlassian.net`. An API token is preferred: `codapact-confluence auth login
--scheme basic` with your Atlassian email and a token from
https://id.atlassian.com/manage-profile/security/api-tokens. Where API tokens are
disabled, `codapact-confluence auth login --scheme session` opens a browser window for
single sign-on, saves the session cookies in your keyring, and renews them without a
window until your identity provider asks for you again. Browser sign-in needs Chrome,
Edge or `playwright install chromium`.

## Development

The code in `gen/python/` is generated by [Codapact](https://github.com/mikejhill/codapact). Do not edit it; regenerate instead:

```console
uvx codapact==0.14.0 sync --check                                    # has the provider published a new contract?
uvx codapact==0.14.0 sync                                            # pull it into the pinned copy
uvx codapact==0.14.0 generate                                        # run where codapact.yaml is
uv run --directory gen/python pytest                                 # offline: help, dry runs, scenarios
CONFLUENCE_E2E_LIVE=1 uv run --directory gen/python pytest -k live   # read-only calls to the real API
```
